# Kun Tartibi

Terminalda ishlaydigan oddiy vazifalar ro'yxati (to-do) dasturi. Python bilan yozilgan, tashqi kutubxona kerak emas.

## Talab

- Python 3.8 yoki yangi

## Ishlatish

```bash
python main.py add "Git o'rganish"      # vazifa qo'shish
python main.py list                     # ro'yxatni ko'rish
python main.py done 1                   # 1-vazifani bajarildi deb belgilash
python main.py delete 1                 # 1-vazifani o'chirish
```

Namuna natija:

```
1. [x] Git o'rganish
2. [ ] Python mashq
```

Vazifalar `tasks.json` faylida saqlanadi.
